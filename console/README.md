# Web 控制台

浏览器里走完「剧本 → 提示词 → 参考图 → 出视频 → 合成」的界面。

## 怎么启动

推荐（网页 + 自动续接下一段）：

```bash
cd console
python start_daemons.py
```

浏览器打开 http://127.0.0.1:8890 ，改完代码后按 **Ctrl+F5** 强制刷新。

只要网页、不要自动续接时，也可以：`python batch_console.py 8890`。

本机需要已安装 **ffmpeg**（抽最后一帧、合成成片都靠它）。装好后保证命令行能跑 `ffmpeg`，或设置环境变量 `FFMPEG_BIN` 指向 ffmpeg 所在文件夹。

## 8 步流程

1. **创建项目** — 名字不要重复；类型可自填；画幅竖/横会传到出片；总时长按秒填
2. **脚本生成** — 写梗概让 AI 写，或粘贴剧本 / 导入 JSON
3. **改写脚本** — 理顺人物动作和情节
4. **规范提示词** — 逐段扩成 MiniMax H3 提示词，可手改
5. **参考资产** — 角色锚点 / 场景 / 分镜图（锚点图不要随便重画）
6. **预览确认** — 看名称、时长、图、提示词齐不齐
7. **提交生成** — 建议勾选链式衔接；**停止 / 从断点继续 / 状态卡片只看当前项目**
8. **记录与合成** — 失败码、生成记录、一键合成完整成片

演示剧本：`examples/demo_script.json`（第 2 步导入）。

## 第 7 步要注意

- 卡片里只显示**当前打开的项目**，旧项目（比如以前的片子）不会混进来
- **停止**只停当前项目，别的项目继续跑
- 云端任务从队列里消失后，大约 **3 分钟**会标成失败 `F-LOST`，不用空等几十分钟
- 衔接分镜没画成时，卡片会写「衔接分镜没画成，约 45 秒后再试」，不会偷偷用旧分镜

## 文件

| 文件 | 作用 |
|---|---|
| `batch_console.py` | 网页后端：项目 / 剧本 / 资产 / 提交 / 监控 / 合成 |
| `chain_daemon.py` | 后台自动交下一段 |
| `start_daemons.py` | 一键启动上面两个 |
| `index.html` | 前端页面 |
| `rules/` | AI 规则（可在设置里改） |
| `console.db` | 运行数据，**不要提交 git** |

配置在项目根目录 `config.json`（复制 `config.example.json`），说明见 `CONFIG.md`。

完整说明看仓库根目录 [README.md](../README.md)。
